The NOMENCLATURE screen (BO-02-01-08): the whole classification visible ! level by level, which is what a chef de rayon asks for to check an ! integration — and the form that RUNS that integration. ! ! Three ways to write. The published file is INTEGRATED whole — re-integrating ! it is how the classification is refreshed —, the nodes are edited one by one, ! because the finest level belongs to the point of sale, and a node is MOVED by ! dragging it onto its new parent. A node of a national level is overwritten by ! the next integration; the screen says so above the listing rather than ! forbidding the edit. ! ! Moving re-codes: the parent being the prefix, a node dropped elsewhere takes ! its new parent's prefix and its whole descent follows. If the number it ! carries is already taken there, the drop RENUMBERS it — with the first free ! number — instead of refusing: the codes of the target branch are not on the ! operator's screen, so a refusal asked them to solve a problem they could ! neither see nor have caused. The number chosen is said, and the free part of ! every code is a field: what the machine picked, the shop corrects. ! ! Holding a drag over ! ANY closed row opens it after a second — the rayon and the famille being ! crossed as much as the eventual parent — so a target three levels down is ! reachable without letting go. The ROW is what is grabbed — anywhere on it, ! with the grab cursor as the sign — and not the ⠿ beside it: a handle that ! small has to be pointed out before anyone can use it, which is another way ! of saying the tree does not move. ! ! A control is not shown where it cannot act: no cross on a node that still ! has children, no plus on the finest level, no grab cursor on a top node — ! the server refuses all three anyway, and a button that only ever answers a ! refusal teaches the operator to distrust the row it sits on. ! ! The code is never a form field to change: its LENGTH places the node and ! its PREFIX names its parent, so renaming touches the label alone. ! ! Navigation is by PREFIX: opening a node lists the nodes of the level below ! whose code starts with its own. Same rule as the import, so this screen can ! never show a tree the printers would disagree with. !} {#include admin-layout} {#title}Nomenclatures{/title} {#body}
