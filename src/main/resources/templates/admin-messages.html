Messages aux caisses

Ce que le magasin dit a ses caisses : un texte ou un sondage, une periode de diffusion, une population, un moment d'affichage et un accuse de lecture nominatif. La caisse recupere le message a son prochain sondage, dans les vingt secondes.

Ecrire un message

Un message sans texte ni question ne dit rien et est refuse. Pour retirer une consigne, la desactiver.

Separees par des points-virgules : Oui;Non;Sans avis
LC-03-07-06 a -09 : options, nombre saisi, code postal ou message informatif a valider.
LC-03-07-10.
LC-03-07-07 : C par chiffre — CCCCC (France), CCCC (Belgique), CCCC-CCC (Portugal).
LC-03-07-08 : separes par des points-virgules ; vide, seul le format controle.
Obligatoire des que la population n'est pas « toutes les caisses ».
0 : la banniere reste jusqu'a ce qu'un autre message la remplace.
